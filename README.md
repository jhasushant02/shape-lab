# shape-lab

**Dashboards, teardowns, analyses and automations. Messy things, shaped.**

This is where I keep what I build outside of work (and sometimes inside it). Each project starts with something messy, like raw data, a product, or a process, and ends with a clearer picture of what's underneath.

By [Sushant Jha](https://github.com/jhasushant02), Category Manager at Urban Company.

## Repo layout

```text
shape-lab/
├── analytics/
│   └── project-name/
├── teardowns/
├── automation/
├── case-studies/
└── README.md
```

Every project folder follows the same shape:

```text
project-name/
├── README.md      the question, the approach, what I found
├── data/          source files, or a note on where to get them
├── analysis/      queries, notebooks or workbooks
└── output/        dashboard screenshots and exports
```

## Adding a new project

1. Create a folder under the right category.
2. Add a `README.md` using the template below.
3. Add a row to the table in this file.

```markdown
# Project name

**One line on what this is.**

## The question
What was I trying to find out, and why?

## Approach
Data source, tools, and the main steps.

## What I found
The result, in plain words.

## Output
Screenshots or a link to the live dashboard.
```
